# Pistyll Productions website

Static website for Pistyll Productions, hosted on GitHub Pages.

## Structure

- `index.html`: the one-page site (hero, showreel, about, services, kayaking, work, contact)
- `css/style.css`, `js/main.js`
- `image/`: web-sized copies of the photos in `Photos/` (originals stay in `Photos/`)

## Notes

- **Showreel:** `video/showreel.mp4` (720p H.264). Swap the file to update it.
- **Contact form:** sends via Formspree (`data-endpoint` on the `<form>` in `index.html`).
- **Bios:** John's and Huw's bios are still placeholders in the About section.
- `Photos/` holds the full-size originals and is not published.
